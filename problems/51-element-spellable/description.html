Write a recursive function that determines whether a word can be spelled using symbols from the periodic table.

The function receives a word and an array of valid element symbols. Matching should be case-insensitive, but the returned symbols must keep the capitalization from the symbols list.

For example, elementSpellable('began', ['Be', 'Ga', 'N']) should return ['Be', 'Ga', 'N'], while a word that cannot be built from the symbols should return null. The empty string should return [].
