Given an integer, determine whether it is even. Do not use the modulo operator (%).

Function Signature

isEven(n)

Parameters

  • n — an integer, which may be positive, negative, or zero.

Output

Return true if n is even, or false if n is odd.

Constraints

  • The function must use recursion.
  • The modulo operator (%) must not be used.
  • The function should accept exactly one argument.

Examples

isEven(0)   → true
isEven(4)   → true
isEven(7)   → false
isEven(48)  → true
isEven(-14) → true
isEven(-31) → false
