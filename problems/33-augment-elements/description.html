Given an array of arrays and a value, return a new array where the value has been appended to each inner array.

Function Signature

augmentElements(array, aug)

Parameters

  • array — an array of arrays.
  • aug — any value to append to each inner array (number, string, null, false, '', etc.).

Output

Return a new array of arrays, each with aug appended.

Constraints

  • The function must use recursion.
  • The function should accept exactly two arguments.

Examples

augmentElements([[], [3], [7]], 5)     → [[5], [3, 5], [7, 5]]
augmentElements([[], [3], [7]], null)  → [[null], [3, null], [7, null]]
augmentElements([[], [3], [7]], '')    → [[''], [3, ''], [7, '']]
augmentElements([[], [3], [7]], false) → [[false], [3, false], [7, false]]
