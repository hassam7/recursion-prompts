Write a recursive function that decides whether a workout playlist can be built from a list of song lengths.

The playlist must add up exactly to workoutLength, and each song length may be used at most maxTimes. Return true when a valid playlist exists and false otherwise.

Throw an error if workoutLength, maxTimes, or any song length is negative. For example, canMakePlaylist([3, 5, 7], 10, 2) should return true, while canMakePlaylist([4], 12, 2) should return false.
